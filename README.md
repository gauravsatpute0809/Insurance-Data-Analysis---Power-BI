# 📊 Insurance Data Analysis Dashboard – Power BI

## 🧾 Overview

This project is a Power BI dashboard created to analyze insurance data and understand business performance across policies, claims, and customers.

The dashboard focuses on key areas such as premium collection, coverage amount, claim analysis, policy activity, and customer demographics.

---

## 🛠️ What I Worked On

* Imported and connected insurance dataset
* Cleaned and prepared data for analysis
* Built relationships and structured data model
* Created DAX measures for calculations
* Designed an interactive dashboard with filters and visuals

---

## 📊 Dashboard Features

* 💰 Total Premium, Coverage, and Claim Amount KPIs
* 📌 Premium analysis by policy type
* 📉 Claim status distribution (Rejected, Settled, Pending)
* 👥 Customer distribution by gender
* 📊 Active vs Inactive policy analysis
* 📈 Claim amount analysis by age group
* 📋 Detailed table view for policy-wise claim status

---

## 📈 Key Insights

* Travel insurance contributes the highest premium
* Claim amount is significant compared to premium
* Elder customers generate the highest claims
* Active policies are higher than inactive ones
* Rejected claims are more than settled claims
